# Glosario

**Actualizado:** 2026-11-04

| Término | Significado |
|---|---|
| OHLCV | Open, High, Low, Close, Volume: resumen de cada vela |
| Vela (candle) | Intervalo de tiempo con su OHLCV; "cerrada" cuando terminó |
| Spot | Compra/venta directa del activo, sin derivados ni apalancamiento |
| Apalancamiento | Operar con dinero prestado; amplifica ganancias y pérdidas. **Excluido del MVP** |
| Spread | Diferencia entre precio de compra y venta |
| Slippage | Diferencia entre el precio esperado y el obtenido |
| Maker / taker | Orden que agrega liquidez (límite) / que la consume (mercado) |
| Stop-loss | Orden/regla de salida ante pérdida; **no garantiza el precio** |
| Drawdown (DD) | Caída desde un máximo previo del capital; MDD = máximo observado |
| Sharpe | Retorno excedente / volatilidad; ruidoso con pocos datos |
| Profit factor | Ganancias brutas / pérdidas brutas |
| Expectativa | Ganancia media esperada por operación |
| Backtest | Simulación con datos históricos |
| Paper trading | Simulación en tiempo real sin dinero real |
| Look-ahead bias | Usar información que no existía en ese momento |
| Overfitting | Ajustarse al ruido del pasado |
| Data snooping | Probar muchas variantes y reportar la mejor |
| Walk-forward | Reoptimizar y probar en ventanas temporales sucesivas |
| Fuera de muestra (OOS) | Datos no usados para diseñar/ajustar |
| Benchmark | Alternativa de comparación (p. ej. comprar y mantener) |
| DCA | Compras periódicas de monto fijo |
| Idempotencia | Repetir una operación no cambia el resultado (evita órdenes duplicadas) |
| Reconciliación | Comparar el estado local con el del exchange |
| Kill switch | Parada de emergencia |
| PSAV | Prestador de servicios de activos virtuales (Ley Fintech, CMF) |
| CMF / SII / UAF | Comisión para el Mercado Financiero / Servicio de Impuestos Internos / Unidad de Análisis Financiero |
| IGC | Impuesto Global Complementario |
| ADR | Architecture Decision Record |
| PoC | Prueba de concepto |
| CCXT | Librería unificada de conexión a exchanges |
| Parquet / DuckDB | Formato columnar / motor analítico embebido |
